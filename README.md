# Smart Machine Health Monitoring and Failure Prediction System

## Overview
This project is an AI-based predictive maintenance system designed to monitor machine health and predict machine failures using simulated sensor data.

The system continuously analyzes machine parameters such as:
- Temperature
- Vibration
- Sound levels

Based on these values, the machine condition is classified as:
- Normal
- Warning
- Critical

## Technologies Used
